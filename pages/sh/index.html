Bash

Jakýkoliv Unixový terminál (například v Ubuntu) je vlastně „otevřený Bash“, takže příkazy jsou stejné. Liší se jen tím, kam je napíšeme:

  • Do terminálu: pak se jedná o terminálový příkaz.
  • Do souboru: tak se jedné o souborový či scriptovací, tzv. Bash / Shell příkaz.

Všechny příkazy zde byli úspěšně testovány na Ubuntu.
Většina příkazy se napříč Linux distry (linux distribution) řídí shodnými pravidli, jen některé jsou více upravené nebo přidávájí lepší, nebo vlastní příkazy.

Terminálové příkazy

Základy a pohyb

Kdo vlastně jsem? [whoami & who]

whoami & who – vznikli z doslovně anglické otázky “Who am I?” a “Who?” (<>„Kdo jsem?“ a „Kdo?“). Tak trochu odkazují na uživatele. Příkaz whoami říká přímo kdo je daný uživatel, kdežto who říká, kdo všechno je přihlášený. 

            
                whoami
                \\codedocs
                who
                \\codedocs

Parametr se píše pomocí - a lze je kombinovat: ls -la

man příkaz – zkratka ze slova manual (manuál). Vytáhne kompletní dokumentaci k jakémukoli příkazu (ukončení klávesou q jako quit); příkaz --help – stručná nápověda; help – nápověda vestavěných příkazů samotného Bashe.

history – historie (seznam) dříve použitých příkazů, clear – vyčistí (uklidí) obrazovku terminálu, Ctrl + C – storno / okamžité přerušení a ukončení právě běžícího příkazu.

sudo příkaz – pochází ze spojení „SuperUser DO“ (superuživateli, udělej!). Provede danou akci s nejvyššími právy správce (root), poprvé se ptá na heslo.

pwd – zkratka pro „Print Working Directory“ (vypiš pracovní adresář) – jednoduše ti ukáže přesnou cestu, kde zrovna stojíš.

Důležité cesty: / kořenový adresář (KřA), ~/ domovský adresář (DmA, tedy /home/ubuntu2204), . aktuální a .. nadřazený adresář.

            
                cd /
                cd ..
                cd -
                cd ~/
                ls -la
  • cd / cd ~/ – cd znamená „Change Directory“ (změň adresář). Bez parametrů nebo s ~/ tě skokem vrátí do domovského adresáře, cd / – do KřA, cd - – skok zpět do adresáře, ve kterém jsi byl přímo předtím (jako tlačítko zpět).
  • ls – zkratka z „list“ (seznam/výpis adresáře); -l znamená long (dlouhý podrobný výpis s právy a datem), -a znamená all (ukáže i skryté soubory začínající tečkou), -i přidá čísla i-uzlů (i-nodes), -R znamená recursive (vypíše i obsah všech podadresářů).

Jak číst výpis ls -l:

            
-rw-rw-r-- 1 ubuntu2204 ubuntu2204 54 zář  8 14:51 pepa
│└┬┘└┬┘└┬┘ │ │          │          │  └─ datum a čas
│ │  │  │  │ │          │          └──── velikost (B)
│ │  │  │  │ └─────────────── skupina
│ │  │  │  │ └────────────────────────── vlastník
│ │  │  │  └──────────────────────────── počet tvrdých odkazů
│ │  │  └─ práva ostatních (o)
│ │  └──── práva skupiny (g)
│ └─────── práva vlastníka (u)
└───────── typ: - soubor, d adresář, l symlink, p roura

Soubory a adresáře

  • touch soubor – původně slouží k „dotknutí se“ souboru (aktualizaci časového razítka). Pokud ale soubor neexistuje, vytvoří ho prázdný (i více najednou); -d "datum" nastaví přesné datum, -m znamená modification time (přepíše aktuální čas změny souboru) (mění čas změny, nikoli „vytvoření“).
  • mkdir adr – zkratka „Make Directory“ (vytvoř adresář); -p znamená parents – vytvoří celou cestu včetně chybějících nadřazených složek najednou.
  • rm soubor – zkratka z „remove“ (odstranit) – smaže bez ptaní; rm -R adr smaže rekurzivně i plný adresář; rmdir adr znamená „Remove Directory“ – smaže výhradně prázdný adresář.
  • cp a b – zkratka z „copy“ (kopírovat); cp a cesta/ kopie jinam; cp -r adr cesta/ rekurzivně nakopíruje celý adresář.
  • mv a cesta/ – zkratka z „move“ (přesunout); mv a novejmeno – v Linuxu se přesun na stejné místo používá jako přejmenování.
  • cat – zkratka z „concatenate“ (spojit). Původně sloužil ke spojování souborů, ale nejčastěji se používá na rychlý výpis obsahu souboru do terminálu (-n number – očísluje řádky, -b jen neprázdné, -s sloučí prázdné, -A ukáže $ na konci řádků), tac – přečtené jméno cat pozpátku – vypíše řádky v obráceném pořadí od konce.
  • head -n5 soubor / tail -n5 soubor – zkratky pro „hlavu“ (začátek) a „ocas“ (konec). Vypíší prvních / posledních 5 řádků (výchozí je 10).
  • sort – z anglického „seřadit“ – srovná řádky podle abecedy (-r reverse – opačně, -n numeric – podle čísel, -u unique – ponechá jen unikátní řádky, -f bez rozlišení velikosti).
  • wc -l soubor – wc znamená „Word Count“ (počet slov); přepínač -l (lines) spočítá čistě řádky; samotné wc vypíše řádky, slova a bajty.
  • grep vzor soubor – pochází z historického příkazu editoru ed: Global / Regular Expression / Print. Hledá v textu řádky odpovídající vzoru; -v vyhledá opačně (řádky, kde vzor NENÍ), -q quiet – nic nevypíše, vrátí jen návratový kód.
  • soffice soubor (LibreOffice), open soubor, nano soubor – otevření / úprava.

Pozor: rm * smaže vše v aktuálním adresáři, vždy kontroluj, kde stojíš.

Přesměrování a roury

Každý proces má tři proudy: 0 standardní vstup (stdin), 1 standardní výstup (stdout), 2 chybový výstup (stderr). Symbol > je zkratka pro 1>, < pro 0<.

  • příkaz > soubor – zapíše výstup; soubor vytvoří, existující přepíše
  • příkaz >> soubor – připojí na konec (neporuší obsah)
  • příkaz < soubor – vstup ze souboru (musí existovat)
  • příkaz 2> /dev/null – chybové hlášky pošle do „černé díry“ Linuxu (soubor /dev/null), tedy je zahodí
  • příkaz1 | příkaz2 – kolona (roura / pipe): výstup prvního je vstupem druhého
  • tee soubor – pojmenováno podle T-spojky na potrubí. Výstup pošle dál na obrazovku a ZÁROVEŇ odbočkou uloží do souboru
            
echo "Ahoj" > a.txt
echo "Dál" >> a.txt
cat /etc/passwd | grep -v systemd | grep -v /var | tee vystup
ls | sort -r > reverzne

Pojmenovaná roura je speciální soubor (typ p) pro jednosměrnou komunikaci dvou procesů: producent zapisuje, konzument čte a každý čeká na druhého. Vytvoří se mknod roura p (make node) a po použití se smaže (čtení bez producenta čeká donekonečna).

            
mknod roura p
head /etc/passwd > roura

Ve druhém terminálu: cat roura nebo nl -v 15 roura | tee protokol. Stejný typ souboru vytvoří i mkfifo roura (Make FIFO – First In, First Out).

Práva

Změna práv: chmod [u|g|o|a][+|-|=][r|w|x] soubor (chmod znamená „Change Mode“ – změnit režim/práva souboru), např. chmod o+rx soubor. Volba -R platí i pro obsah adresáře.

  • u user (vlastník), g group (skupina), o others (ostatní), a all (všichni)
  • + přidá, - odebere, = nastaví přesně
  • r read – čtení (hodnota 4), w write – zápis (hodnota 2), x execute – spuštění / vstup do adresáře (hodnota 1)
            
 u   g   o
rwx rwx rwx
421 421 421
-7- -7- -7-      chmod 777 = všem vše, chmod 000 = nikomu nic

546  →  4-1 4-- 42-  →  r-x r--  rw-

Před obvyklé tři číslice se přidává čtvrtá pro speciální bity: 4 SUID, 2 SGID, 1 sticky bit.

  • SUID – Set User ID. Spustitelný soubor běží s právy vlastníka, ne toho, kdo ho spustil (proto může běžný uživatel změnit heslo přes passwd). V ls -l je s místo x u vlastníka: -rwsr-xr-x (chmod 4755).
  • SGID – Set Group ID. U souboru běží s právy skupiny; u adresáře dědí nové soubory skupinu adresáře (vhodné pro týmy). s u skupiny: drwxrwsr-x (chmod 2775).
  • Sticky bit – „lepkaný bit“. U adresáře zabraňuje uživatelům mazat cizí soubory (smí je smazat jen jejich vlastník, vlastník adresáře nebo root, např. složka /tmp). t u ostatních: drwxrwxrwt (chmod 1777).

Velké S / T ve výpisu znamená, že bit je nastaven, ale příslušné x chybí.

Odkazy a i-uzly

Soubor má dvě nezávislé části: i-uzel (i-node / index node – unikátní datová struktura uchovávající metadata jako velikost, vlastníka, práva či časy) a jméno v adresáři, což je jen tabulka „jméno → číslo i-uzlu“.

  • Tvrdý odkaz (ln soubor odkaz, kde ln je zkratka pro link) je další jméno ukazující na stejný i-uzel. Počet je vidět v ls -l; data zmizí z disku, až počet odkazů klesne na 0. Nejde vytvářet na adresáře ani přes různé diskové oddíly.
  • Měkký odkaz (ln -s cíl odkaz, kde -s znamená symbolic – symlink) je malý samostatný soubor obsahující textovou cestu k cíli. Má vlastní i-uzel (ls -li), funguje i na adresáře a jiné disky, ale po smazání původního cíle přestane fungovat (vznkne tzv. mrtvý odkaz).
  • Adresář má vždy odkazy . (sám na sebe) a .. (nadřazený). Každý podadresář přidá další.
            
ln -s soubor.txt zastupce
ls -l
lrwxrwxrwx 1 ubuntu2204 ubuntu2204 10 pro  2 10:02 zastupce -> soubor.txt

Procesy a úlohy

  • příkaz & – spustí na pozadí, prompt je hned volný; Ctrl+Z pozastaví úlohu v popředí
  • jobs – vypíše seznam úloh běžících v aktuálním terminálu (-l s PID, -r běžící, -s pozastavené)
  • fg / bg – zkratky pro foreground (popředí) a background (pozadí) – přesunou úlohu podle potřeby
  • kill %2 – „zabije“ / ukončí úlohu číslo 2 (posílá výchozí ukončovací signál SIGTERM)
  • ping adresa – odvozeno od ponorkového sonaru – posílá kontrolní pakety pro ověření dostupnosti sítě; sleep 600 – příkaz „uspí“ skript / terminál na 600 sekund (10 minut)
            
ping www.seznam.cz
^Z
[1]+  Pozastavena             ping www.seznam.cz
bg
kill %1

Výstup procesu na pozadí se dál píše do terminálu (jako u ping výše); Ctrl+C ukončuje jen úlohu v popředí.

Kalkulačka bc

bc (Basic Calculator) počítá s libovolnou přesností. Přepínač -l zapne matematickou knihovnu (math library), scale určuje přesný počet desetinných míst, ibase / obase znamenají input/output base (vstupní / výstupní číselná soustava, výchozí je 10), ukončení provedete příkazem quit.

            
echo 'scale=5; sqrt(5)' | bc -l
2.23606
echo 'scale=120; 4*a(1)' | bc -l
3.14159265358979323846264338327950288419716939937510582097494459230781640628620899862803482534211706798214808651328230664
echo '2*3^2' | bc
18

a() je arkus tangens (v radiánech, kde arctan(1) = π/4), proto 4*a(1) dává π. Převod soustav: obase=16, pak 31 vypíše 1F.

Souborové příkazy (skripty)

Skript a spuštění

Posloupnost příkazů, kterou chceš používat opakovaně, uložíš do souboru a necháš ho provést interpretem. Cestu k němu udáváš v prvním řádku (#!/bin/bash) – této kombinaci znaků #! se v unixovém světě říká shebang (z kombinace hash # a bang !) a říká systému, jaký program má tento skript přečíst a vykonat. Soubor bývá bez přípony nebo s .sh; kdo ho chce spouštět přímo, potřebuje spouštěcí právo x.

            
#!/bin/bash
# komentář
x=5
echo "Hodnota proměnné x je $x."
  • sh skript / bash skript – spustí novým shellem
  • . skript – provede ho aktuálním shellem (změny proměnných zůstanou v tvém terminálu)
  • chmod +x skript a pak ./skript – spustí podle řádku #!

Proměnné a vstup

  • Proměnné se nedeklarují, typ vznikne prvním použitím. Přiřazuješ bez $ a bez mezer kolem = (x=5), čteš s $ ($x).
  • echo "text $x" – výpis; read x – přečte a načte řádek z klávesnice od uživatele; read a b c – rozdělí podle mezer do více proměnných
  • read -p "Zadej věk: " age – s výzvou (prompt). Volba -p funguje v Bashi, ale ne v sh (na Ubuntu je to dash).
  • "…" – proměnné se dosadí; '…' – čistý text, nic se nedosazuje; `příkaz` – provede příkaz a dosadí jeho výstup (dnes se píše $(příkaz))
  • echo -e "a\nb" – pro \n ve výpisu; bez -e to Bash vypíše doslova.
            
#!/bin/bash
echo "SČÍTÁNÍ"
read -p "Zadej x: " x
read -p "Zadej y: " y
z=$((x+y))
echo "$x + $y =$z"

Výrazy a testy

Počítání celých čísel: $((a+b)), $((a\%b)) (zbytek), starší expr $x + 1. Desetinná čísla: echo "scale=2; 10/3" | bc.

Logické výrazy se píšou do [ výraz ] (mezery uvnitř závorek jsou povinné) – hranatá závorka [ je v Bashi doslova zkratka pro příkaz test:

  • Soubory: -f (file – je to běžný soubor), -d (directory – je to adresář), -r -w -x (lze číst / zapisovat / spustit), -O (owner – vlastníkem jsem já), -N (newer – změněn od posledního čtení)
  • Řetězce: a = b, a != b, -z s (zero – řetězec je prázdný), -n s (non-zero – řetězec není prázdný) (< a > je nutné psát \< a \>)
  • Čísla: používají zkratky z angličtiny: -eq (equal), -ne (not equal), -lt (less than), -le (less or equal), -gt (greater than), -ge (greater or equal)
  • Spojování: [ a ] && [ b ] (a zároveň), || (nebo)

Podmínky if a case

            
if [ $age -lt 18 ]; then
    echo "Nejsi plnoletý."
elif [ $age -le 64 ]; then
    echo "Jsi dospělý."
else
    echo "Jsi senior."
fi

else if není elif: po else if je potřeba druhé fi, což je častá chyba. Všimni si, že bloku if odpovídá ukončovací fi (slovo if pozpátku). Podmínkou může být i příkaz: if grep -q roman /etc/passwd; then ….

case je větvení podle hodnoty, jako switch jinde. Celá konstrukce končí slovem esac (opět slovo case zapsané pozpátku). Platí první shoda, ;; ukončuje větev, * je výchozí.

            
#!/bin/bash
read -p "Znak: " znak
case $znak in
    [0-9]) echo "Číslo." ;;
    [A-Z]) echo "Velké písmeno." ;;
    [a-z]) echo "Malé písmeno." ;;
    *)     echo "Jiný znak." ;;
esac

Cykly

  • for – předem známý seznam (položky oddělené mezerou); místo seznamu může být zástupný znak
  • while – běží, dokud je podmínka splněná
  • until – běží, dokud podmínka splněná není
            
for i in 1 3 5 7
do
    echo $i
done

for f in *
do
    if [ -f "$f" ]; then echo "$f je soubor"; fi
done

x=0
while [ $x -le 10 ]
do
    echo "x je $x"
    x=$((x+1))
    sleep 1
done

until who | grep -q huzva
do
    sleep 20
done
echo "Už se přihlásil"

for, do a done píš na samostatné řádky (nebo je odděl středníkem: for i in 1 2; do echo $i; done).

Ukázkové skripty

Dělitelnost: číslo končí osmičkou a je dělitelné třemi.

            
#!/bin/bash
read -p "Napiš číslo: " num
if [ $((num \% 10)) -eq 8 ] && [$((num % 3)) -eq 0 ]; then
    echo "Končí 8 a je dělitelné 3."
else
    echo "Nesplňuje."
fi

Pythagorova věta s bc a ošetřením záporných vstupů:

            
#!/bin/bash
read -p "Odvěsna a: " a
read -p "Odvěsna b: " b
if [ $a -le 0 ] \vert{}\vert{} [$b -le 0 ]; then
    echo "Zadej hodnoty větší než 0!"
else
    echo "c = $(echo "scale=2; sqrt($a^2 +$b^2)" | bc -l)"
fi

Kalkulačka pomocí case a bc:

            
#!/bin/bash
read -p "Zadej a operátor b (oddělené mezerou): " a op b
case $op in
    +|-|/) echo "scale=2; $a $op$b" | bc -l ;;
    x|\*)  echo "scale=2; $a * $b" | bc -l ;;
    *)     echo "Neznámá operace." ;;
esac

Užitečné doplňky: $1, $2 jsou argumenty skriptu, $# jejich počet, $? návratový kód posledního příkazu (0 = úspěch) a exit 1 skript ukončí s chybou.
