Soukromé poznámky pro práci s PrismJS

Tato stránka slouží jako přehledná nápověda a tahák pro použití jednotlivých pluginů knihovny PrismJS v projektu CodeDocs.

Hlavní struktura

PrismJS je speciální "kódování", která nám zajišťuje barevné parsování kódových blocků.

Píše se pomocí značky <pre> a v ní vnořené značky <code> se třídou určující jazyk v něm.

Vzhled je velmi jednoduchý:

            
                <pre>
                    <code class="language-txt">
                        Prostor pro kód
                    </code>
                </pre>

                <!-- nebo -->

                <pre>
                    <code class="lang-txt">
                        Prostor pro kód
                    </code>
                </pre>

Pluginy se pak píší převážně jako třída či jiné atributy značky <pre>, ale mouhou se psát i do <body>, chceme-li, aby platila pro veškeré kódy. (viz níže)

Číslování řádků

Line Numbers

Line Numbers funguje velmi jednoduše. Stačí nám do třídy <pre> napsat line-numbers a získáme očíslování. Lze ho zapsat i do jiných značek jako je třeba <body>, což aplikuje tento plugin na veškeré vnořené kódy.

Pro jeho případné vypnutí pak funguje no-line-numbers. Slouží primárně pro druhé zmíněné použití.

Ukázka: 
            
                <!DOCTYPE html>
                <html lang="en">
                <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>Document</title>
                </head>
                <body>
                    |
                </body>
                </html>

Také můžeme využít atribut data-start, který nám řáká, od jakého řádku máme začít:

Ukázka: 
            
                    <title>Document</title>
                </head>
                <body>
                    |
                </body>
                </html>

Což nám perfektně dokáže ukazovat vnitřky kódu bez starostí.

Zvýraznění řádků

Line Highlight

Pro Line Highlight potřebujeme speciální atribut data-line. Díky němu dokážeme zvíraznit potřebné řádky.

Line Highlight má speciální vlastnost. Napíšeme-li ho jako jediný atribut značky <pre>, sám nám ukáže kolikátý řádek kódu je zvýrazněný:

Ukázka 1: 
            
                <!DOCTYPE html>
                <html lang="en">
                <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>Document</title>
                </head>
                <body>
                    |
                </body>
                </html>

Zde jsme použili data-line="1, 4-6", což nám krásně ukazuje jak jednořádkové tak více řádkový zvýraznění. A nyní s Line Numbers:

Ukázka 2: 
            
                <!DOCTYPE html>
                <html lang="en">
                <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>Document</title>
                </head>
                <body>
                    |
                </body>
                </html>

Ukázání jazyka

Show Language

Show Language ukazuje jazyk podle toho, co napíšeme do language-xxxx (případně lang-xxxx).

Napíšeme-li lang-py, získáme Python. Stejně tak můžeme napsat i python.

Ukázka: 
            
                text = "Tohle je Python."

Můžeme však využít i atribut data-language, kterým určíme, co přesně máme ukázat. Místo klasického HTML tak můžeme napsat klidně: data-language="HyperText Markup Languages".

Ukázka: 
            
                <p>Tohle je HTML.</p>

Je nutné dodat, že aby nám toto fungovalo, potřebujeme také Toolbar.

❌ Náhled barevných kódů

Inline Color

Inline Color by mělo zobrazovat malý čtvereček před barvou, ale z neznámích důvodů to zde nefunguje.

            
                .box {
                    background-color: #ff5733;
                    color: rgba(0, 0, 0, 0.8);
                }

Příkazová řádka

Command Line

Command Line složí primárně pro skriptování. Pro zobrazení potřebujeme značce <pre> dát třídu command-line. Tím nám PrismJS automaticky vygeneruje základní adresu [user@localhost] $.

Ukázka: 
            
                whoami

Chceme-li však, tuto adresu upravit, musíme použít data-user a data-host:

Pro příklad použijeme data-user="ubuntu" a data-host="host".

Ukázka: 
            
                whoami

Když už máme v ukázce příkaz whoami, chtělo by to nějaký ten výstup, že?

Ukázka výstupu: 
            
                    whoami
                    [ubuntu@host]

Zde jsme použili atribut data-output, který řekne, které řádky jsou výstupem. Takže v Ukázka výstupu jsme použili data-output="2".


Pro lepší prompt, třeba v Powershellu, se využívá atribut data-prompt.

Ukázka: 
            
                whoami
                CodeDocs\host

Dále tu máme také je data-filter-output, který složí pro jednoduší odfiltrování výstupu. A data-continuation-str sloužící jako pokračování příkazu třeba pro příkaz echo:

Ukázka: 
            
                export MY_VAR=123
                echo "hello"
                (out)hello
                echo one \
                two \
                three
                (out)one two three
                (out) 
                echo "goodbye"
                goodbye
Zápis ukázky: 
            
                <pre
                    class="command-line"
                    data-filter-output="(out)"
                    data-continuation-str="\"
                >
                    <code class="lang-bash">
                        export MY_VAR=123
                        echo "hello"
                        (out)hello
                        echo one \
                        two \
                        three
                        (out)one two three
                        (out) 
                        echo "goodbye"
                        goodbye
                    </code>
                </pre>

Dále tu máme třeba podobné data-filter-continuation, která naopak je podobná data-continuation-str a data-continuation-prompt, který určuje co přesně se ukáže na daném pokračovacím řádku:

Ukázka: 
            
                set @my_var = 'foo';
                set @my_other_var = 'bar';
                (out)
                CREATE TABLE people (
                (con)first_name VARCHAR(30) NOT NULL,
                (con)last_name VARCHAR(30) NOT NULL
                (con));
                (out)Query OK, 0 rows affected (0.09 sec)
                (out)
                insert into people
                (con)values ('John', 'Doe');
                (out)Query OK, 1 row affected (0.02 sec)
                (out)
                select *
                (con)from people
                (con)order by last_name;
                (out)+------------+-----------+
                (out)| first_name | last_name |
                (out)+------------+-----------+
                (out)| John       | Doe       |
                (out)+------------+-----------+
                (out)1 row in set (0.00 sec)
Zápis ukázky: 
            
                <pre
                    class="command-line"
                    data-prompt="MySQL>"
                    data-continuation-prompt="->"
                    data-filter-output="(out)"
                    data-filter-continuation="(con)"
                >
                    <code class="lang-sql">
                        set @my_var = 'foo';
                        set @my_other_var = 'bar';
                        (out)
                        CREATE TABLE people (
                        (con)first_name VARCHAR(30) NOT NULL,
                        (con)last_name VARCHAR(30) NOT NULL
                        (con));
                        (out)Query OK, 0 rows affected (0.09 sec)
                        (out)
                        insert into people
                        (con)values ('John', 'Doe');
                        (out)Query OK, 1 row affected (0.02 sec)
                        (out)
                        select *
                        (con)from people
                        (con)order by last_name;
                        (out)+------------+-----------+
                        (out)| first_name | last_name |
                        (out)+------------+-----------+
                        (out)| John       | Doe       |
                        (out)+------------+-----------+
                        (out)1 row in set (0.00 sec)
                    </code>
                </pre>

data-continuation-prompt má v default nastavení právě >.

Normalize Whitespace

Normalize Whitespace

Automaticky odstraňuje zbytečné odsazení a prázdné řádky na začátku a konci kódového bloku u značek <pre>, takže kód vypadá vždy čistě bez ohledu na formátování HTML.

Ukázka: 
            
                // Tento plugin funguje automaticky na pozadí pro všechny bloky.
                // Lze ho případně konfiguruje v JS skriptu:
                Prism.plugins.NormalizeWhitespace.setDefaults({
                    'remove-trailing': true,
                    'remove-indent': true,
                    'left-trim': true,
                    'right-trim': true
                });
Zápis ukázky: 
            
                <!DOCTYPE html>
                <html lang="cs">
                <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>Zápis ukázky</title>
                    <link rel="stylesheet" href="./styles/prism.css">
                </head>
                <body>
                    <main>
                        <pre class="no-whitespace-normalization">
                            <code class="lang-javascript">
                                // Tento plugin funguje automaticky na pozadí pro všechny bloky.
                                // Lze ho případně konfiguruje v JS skriptu:
                                Prism.plugins.NormalizeWhitespace.setDefaults({
                                    'remove-trailing': true,
                                    'remove-indent': true,
                                    'left-trim': true,
                                    'right-trim': true
                                });
                            </code>
                        </pre>
                    <script src="./utils/prism.js"></script>
                </body>
                </html>

Nástrojová lišta (Toolbar)

Toolbar

Základní panel nad kódovým blokem, který slouží jako kontejner pro tlačítka a informace. Máme zde Název jazyka a Tlačítko pro kopírování.

Tlačítko Kopírovat

Copy to Clipboard Button

Přidá do horní lišty kódu tlačítko, které uživateli umožní jedním kliknutím zkopírovat celý kód do schránky.

Je nutné dodat, že aby nám toto fungovalo, potřebujeme také Toolbar.

data-prismjs-copy je default zpráva, která se zobrazí před kliknutím.

data-prismjs-copy-error je zpráva zobrazená po špatném zkopírovaní.

data-prismjs-copy-success je zpráva zobrazující se po úspěšném zkopírovaní.

data-prismjs-copy-timeout je časovač (v milisekundách) po zkopírování. Určuje, jak dlouho se zobrazí zpráva po kliknutí na tlačítko.

Ukázka: 
            
                Tohle je ukázka Kopírovacího tlačítka.

V tomto dokumentu se tlačítko zobrazuje neustále, ale v originálu se zobrazí až po najetí na blok kódu.

Zvýraznění shodných závorek

Match Braces

Match Braces vytváří jednoduché a přehledné zvýrazňování závorek, zapomoci najetí nebo kliknutí na závorky.

K jeho zapnutí složí match-braces, který kolem závorek vytvoří obdelníček.

Chceme-li, aby byli vidět ihned bez najíždění či klikání stačí použít rainbow-braces, která je zbarví do barevna, ale nepodporuje obdelníčkové zobrazení.

Lze také použít no-brace-hover, aby se nezvýrazňovali při najetí, nebo no-brace-select, aby se nedokázali vybrat.

Tyto třídy lze kombinovat a vytvořit tak barevné zobrazovací závorky.

Ukázka 1 (match-braces): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 2 (match-braces | no-brace-hover): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 3 (match-braces | no-brace-select): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 4 (match-braces | no-brace-hover | no-brace-select): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 5 (match-braces | rainbow-braces): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 6 (match-braces | rainbow-braces | no-brace-hover): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 7 (match-braces | rainbow-braces | no-brace-select): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
Ukázka 8 (match-braces | rainbow-braces | no-brace-hover | no-brace-select): 
            
                function test() {
                    if (true) {
                        console.log([1, 2, 3]);
                    }
                }
