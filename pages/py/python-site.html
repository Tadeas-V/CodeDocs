Python

Jednoduchý jazyk, který se čte skoro jako běžná angličtina. Tady si projdeš základy krok za krokem.

Úvod

Python se hodí na skripty, weby, analýzu dat i automatizaci. Kód se zapisuje bez složených závorek a bloky se určují odsazením.

Tip: Spuštění v terminálu: python ahoj.py. Na některých systémech se příkaz jmenuje python3.

Proměnné a typy

Proměnná vzniká přiřazením. Typ určuje Python sám podle hodnoty.

  • str – text
  • int, float – čísla
  • bool – True nebo False

Podmínky

Větvení programu zajišťují if, elif a else. Za podmínkou následuje dvojtečka a odsazený blok.
